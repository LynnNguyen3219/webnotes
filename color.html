color

hex color

hex color is done in an #rrggbb format, or if you are doing web safe colors, you will do an rgb format.

syntax is easy: #aaa or #fc8826

rgba

rgba color is done in an 0-255,- 0-255, 0-255, 0-1, with the last one being a decimal. this stands for red, green, blue, alpha format

syntax is more tricky: rgba(135, 25, 200, 0.4)
